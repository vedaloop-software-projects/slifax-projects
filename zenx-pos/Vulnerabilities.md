# ZenxPOS legacy vulnerability register

This register records security weaknesses confirmed during the Laravel-to-Node.js migration. It is a static source review, not evidence that an attack or breach has occurred. The **Data Breach** column describes the information or capability that could be exposed if the issue were exploited.

Update this file whenever another legacy weakness is confirmed. Do not add speculative findings without source evidence. Resolution values mean:

- **Resolved:** implemented and covered by the Node test suite.
- **In progress:** replacement work has started but is not complete.
- **Planned:** confirmed issue whose owning migration stage has not been converted.
