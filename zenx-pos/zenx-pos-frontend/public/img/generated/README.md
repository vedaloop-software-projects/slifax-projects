# ZenX POS generated artwork

Generated with the built-in `image_gen.imagegen` tool (not the CLI fallback). All requests set `transparent_background: true`. Original PNGs are preserved; WebP versions are format-compressed copies made with Sharp at quality 86 and alpha quality 100. Standard illustrations are 1536 × 1024 pixels; the pricing panorama is 2172 × 724 pixels. Alpha channels were verified after copying.
